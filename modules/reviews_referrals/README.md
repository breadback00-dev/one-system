# Reviews And Referrals Module

Post-visit review flows, referral sequences, and reputation growth logic.

## Current Capabilities

- Previews post-visit review/referral readiness without queueing outreach.
- Queues review/referral request outreach for contacts with completed visits.
- Auto-queues post-visit review requests when appointments are marked completed.
- Routes inbound post-visit replies into promoter follow-up or service-recovery follow-up messaging.
- Generates operator review-response drafts with sentiment, confidence, and next-action guidance.
- Applies campaign-key cooldown checks before queueing repeat requests.
- Reports queued, delivered, replied, promoter-signal, and referral-intent outcomes.
